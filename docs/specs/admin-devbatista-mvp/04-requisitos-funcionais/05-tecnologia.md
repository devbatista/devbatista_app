# Requisitos funcionais — Tecnologia

[← Requisitos funcionais](README.md) · [Índice geral](../README.md)

29. **Aplicações.** Como desenvolvedor, quero cadastrar cada sistema, site ou app com ambiente, URL, tecnologia, repositório e hospedagem.
    - Hospedagem aponta para um servidor ou um serviço externo. Status: Ativa, Em manutenção, Desativada.
30. **Servidores.** Como desenvolvedor, quero registrar servidores com fornecedor, IP ou hostname, ambiente, SO e custo mensal.
31. **Domínios.** Como desenvolvedor, quero acompanhar domínios com registrador, vencimento, renovação automática e custo.
    - Alertas a 60, 30 e 7 dias do vencimento; domínio sem renovação automática tem destaque na lista.
32. **Bancos de dados.** Como desenvolvedor, quero registrar o banco de cada aplicação com tecnologia, versão, ambiente e provedor.
33. **Integrações.** Como desenvolvedor, quero registrar as integrações de cada aplicação (Meta, WhatsApp, Twilio, OpenAI, SES, Mailgun, PayPal etc.).
34. **Serviços externos.** Como financeiro ou desenvolvedor, quero registrar os SaaS usados por cliente com custo, moeda, periodicidade e quem paga.
    - Quem paga: DevBatista ou Cliente. Só os pagos pela DevBatista entram no custo direto do cliente.
    - Nenhum módulo de Tecnologia aceita senha, chave ou token; só a referência ao cofre de senhas.
